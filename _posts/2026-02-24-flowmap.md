**Velocity → next direction. Flow map → destination.**

Convention: $x_0$ is data, $x_1$ is noise. Generation runs $1\to0$; $v=dx/dt$ points toward increasing time.

## 1. Learn the local velocity

[Diffusion](https://arxiv.org/abs/2006.11239) learns to remove noise. [Flow Matching](https://arxiv.org/abs/2210.02747) learns velocity directly. For straight training paths:

$$
x_t=(1-t)x_0+tx_1,\qquad v_c=x_1-x_0.
$$

{% include figure.liquid path="assets/img/blogs/flowmap/diffusion.svg" mobile_path="assets/img/blogs/flowmap/diffusion-mobile.svg" alt="A Gaussian noise cloud becomes two data clusters as time decreases from one to zero." caption="Toy marginals of the linear interpolation." width=960 height=310 mobile_width=400 mobile_height=810 zoomable=true avoid_scaling=true %}

Train $v_\theta(x_t,t)$ against $v_c$ with squared error. It learns the conditional average:

$$
v(x,t)=\mathbb E[v_c\mid x_t=x].
$$

**Straight training segments can produce curved sampling paths.** [Rectified Flow](https://arxiv.org/abs/2209.03003) straightens transport by retraining on noise–endpoint pairs from the current sampler.

## 2. Learn the whole jump

An Euler step freezes the starting velocity. A flow map integrates the trajectory:

$$
\begin{aligned}
\text{Euler:}\quad x_s&\approx x_t+(s-t)v(x_t,t),\\
\text{Map:}\quad\Phi(x_t,t,s)&=x_t+\int_t^s v(x_\tau,\tau)\,d\tau.
\end{aligned}
$$

{% include figure.liquid path="assets/img/blogs/flowmap/transport.svg" mobile_path="assets/img/blogs/flowmap/transport-mobile.svg" alt="Orange Euler extrapolation misses the destination of a curved blue path. The teal flow-map arrow connects the endpoints." width=960 height=440 mobile_width=400 mobile_height=420 zoomable=true avoid_scaling=true %}

**Exact velocity still needs integration.** For $\dot x=x$, $x_1=1$, the exact destination is $x_0=e^{-1}\approx0.368$.

| Method                            | Predicted $x_0$ |
| --------------------------------- | --------------: |
| 1 Euler step                      |               0 |
| 2 Euler steps                     |           0.250 |
| 4 Euler steps                     |           0.316 |
| Exact map: $\Phi(x,t,s)=e^{s-t}x$ |           0.368 |

A valid map preserves identity and composition:

$$
\begin{gathered}
\Phi(x,t,t)=x,\\
\Phi(x,t,s)=\Phi\big(\Phi(x,t,r),r,s\big).
\end{gathered}
$$

[Consistency Models](https://arxiv.org/abs/2303.01469) send states on one trajectory to the same clean endpoint. Two-time maps allow a requested destination time.

## 3. MeanFlow: predict the average

[MeanFlow](https://arxiv.org/abs/2505.13447) learns average velocity $u$ over $[r,t]$:

$$
(t-r)u(x_t,r,t)=\int_r^t v(x_\tau,\tau)\,d\tau.
$$

{% include figure.liquid path="assets/img/blogs/flowmap/meanflow-jvp.svg" mobile_path="assets/img/blogs/flowmap/meanflow-jvp-mobile.svg" alt="The area under a changing velocity equals a rectangle with height equal to average velocity." width=960 height=345 mobile_width=400 mobile_height=660 zoomable=true avoid_scaling=true %}

Differentiate with $r$ fixed:

$$
u+(t-r)\frac{du}{dt}=v,
\qquad \frac{du}{dt}=J_xu\,v+\partial_tu.
$$

The **Jacobian-vector product (JVP)** includes both state and time changes. Training uses the sampled velocity $v_c$:

$$
\begin{gathered}
D_\theta=\operatorname{JVP}[u_\theta;(v_c,0,1)],\\
\mathcal L=\mathbb E\left\|u_\theta-\operatorname{sg}\left[v_c-(t-r)D_\theta\right]\right\|^2.
\end{gathered}
$$

$\operatorname{sg}$ stops gradients through the target. At $r=t$, this becomes velocity regression.

**Sampling:** $x_r=x_t-(t-r)u_\theta(x_t,r,t)$. One-step generation uses $(t,r)=(1,0)$. No inference JVP; no teacher required.

| Variant                                                  | Main change                                                            |
| -------------------------------------------------------- | ---------------------------------------------------------------------- |
| [iMF](https://arxiv.org/abs/2512.02012)                  | Predicted marginal velocity as JVP tangent; adjustable guidance scale. |
| [AlphaFlow](https://arxiv.org/abs/2510.20771)            | Curriculum from velocity fitting toward trajectory consistency.        |
| [Accelerated training](https://arxiv.org/abs/2511.19065) | Learn local velocity and short intervals before long intervals.        |
| [Decoupled MeanFlow](https://arxiv.org/abs/2510.24474)   | Early blocks use current time; final blocks use destination time.      |

## 4. TVM: move the destination

[Terminal Velocity Matching](https://arxiv.org/abs/2511.19797) holds the input fixed and differentiates the **destination time**.

{% include figure.liquid path="assets/img/blogs/flowmap/endpoint-derivatives.svg" mobile_path="assets/img/blogs/flowmap/endpoint-derivatives-mobile.svg" alt="MeanFlow changes the starting point along the path while the destination stays fixed. TVM fixes the start and changes the destination." width=960 height=365 mobile_width=400 mobile_height=670 zoomable=true avoid_scaling=true %}

For displacement $f(x_t,t,s)=\Phi(x_t,t,s)-x_t$:

$$
\partial_s f(x_t,t,s)=v\big(x_t+f(x_t,t,s),s\big).
$$

Parameterize $f_\theta=(s-t)F_\theta$ to enforce zero displacement at $s=t$. Train the terminal derivative against a stopped, moving-average velocity target; anchor diagonal velocity with Flow Matching.

**Training difference:** MeanFlow detaches its JVP target. TVM backpropagates through its JVP. Both sample without JVPs.

## 5. Match the output distribution

Accurate jumps and accurate sample statistics need different supervision.

[DMD](https://arxiv.org/abs/2311.18828) compares scores $s_p=\nabla_x\log p$ and $s_q=\nabla_x\log q$ of target and generated distributions at matched noise levels.

{% include figure.liquid path="assets/img/blogs/flowmap/dmd.svg" mobile_path="assets/img/blogs/flowmap/dmd-mobile.svg" alt="The target Gaussian is centered at minus one and the student at plus one. Score-difference descent moves samples left toward the target." caption="Toy Gaussians: p = N(−1, 1), q = N(+1, 1), at one noise level." width=960 height=360 mobile_width=400 mobile_height=395 zoomable=true avoid_scaling=true %}

1. Generate samples; add noise.
2. Fit an auxiliary denoiser to generated samples.
3. Compare its score with the teacher score on the **same noisy sample**.
4. Backpropagate the detached difference through the generator.

For $x_t=\alpha_tG_\theta(z)+\sigma_t\epsilon$, the distribution-loss gradient is

$$
\nabla_\theta\mathcal L=
\mathbb E\left[w(t)\alpha_t J_\theta G_\theta^\top(s_{q,t}-s_{p,t})\right].
$$

Original DMD also adds paired regression.

| Method                                        | Supervision                                                                                               |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| [VSD](https://arxiv.org/abs/2305.16213)       | Teacher score minus rendered-image score; update 3D scenes through a renderer.                            |
| [SiD](https://arxiv.org/abs/2404.04057)       | Score identities turn squared score mismatch into a denoising loss; differentiate through score networks. |
| [ADD](https://arxiv.org/abs/2311.17042)       | Image-feature discriminator + diffusion teacher.                                                          |
| [LADD](https://arxiv.org/abs/2403.12015)      | Discriminator on latent diffusion features; avoid pixel decoding.                                         |
| [DiffRatio](https://arxiv.org/abs/2502.08005) | Noisy real/fake classifier estimates the log density ratio; no teacher score.                             |

## 6. Change what the model sees

**[FreeFlow](https://arxiv.org/abs/2511.19428): no external dataset.** Sample noise, query the teacher along student-predicted paths, correct accumulated error.

**[Meta Flow Maps](https://arxiv.org/abs/2601.14430): multiple completions.** Fresh auxiliary noise $\eta$ samples the clean posterior conditioned on the same $x_t$:

$$
x_0^{(k)}=H_\theta(\eta_k;x_t,t),\qquad\eta_k\sim\mathcal N(0,I).
$$

{% include figure.liquid path="assets/img/blogs/flowmap/posterior.svg" mobile_path="assets/img/blogs/flowmap/posterior-mobile.svg" alt="A deterministic map has one endpoint per state. A Meta Flow Map uses fresh noise to sample multiple clean completions from the same state." width=960 height=300 mobile_width=400 mobile_height=520 zoomable=true avoid_scaling=true %}

These samples estimate conditional rewards without nested trajectory rollouts.

**[TMD](https://arxiv.org/abs/2601.09881): reuse video features.** A large backbone supplies features to a small transition head. Train transitions, then refine with distribution matching.

**[AAPT](https://papers.nips.cc/paper_files/paper/2025/file/3a9468a918fc65dc9ce7b7bd99f4f0ef-Paper-Conference.pdf): train on generated history.** Adversarially supervise video rollouts; feed generated chunks into later chunks. Cache attention keys and values.

**Measure:** network evaluations (**NFE**), full generation latency, fidelity, diversity, and long-video drift.
